# GateMate Frontend

GateMate is a community-driven hostel parcel pickup application.

## Tech Stack
- Frontend: React.js (JavaScript)
- Build Tool: Vite
- Styling: Tailwind CSS

## Getting Started

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
